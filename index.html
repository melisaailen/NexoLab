Al adjuntar una planilla .xlsx se revisarán las tablas con formato de Excel. Podrás descargar una copia con las celdas identificadas y una hoja con la referencia de colores.

Gráficos recomendados

Lee las tablas reconocibles del libro. Elegí una hoja para ver los gráficos que sus datos permiten construir; cada recomendación explica el formato, qué se puede observar y qué cautelas tener al interpretarlo. Los gráficos describen patrones, no demuestran causas.

Antes de adjuntar: el archivo debe contener datos organizados como tablas de Excel o tablas dinámicas, con encabezados claros y consistentes. Revisá que estén limpios y correctamente transformados —sin filas o columnas mezcladas, encabezados vacíos ni tipos de datos incorrectos—; de lo contrario, el análisis puede verse dificultado y los gráficos sugeridos resultar poco confiables.

Power BI (.pbix) no se puede leer.

Medidas calculables

Adjuntá una tabla estructurada y elegí una hoja para consultar medidas descriptivas: recuentos, valores distintos y frecuentes, promedios, medianas, rangos o cobertura de fechas. Cada tarjeta explica cómo se obtuvo la medida y qué representa. Se usan las filas válidas de las tablas; no se generan KPI automáticamente porque hace falta definir un objetivo de negocio, una meta y un período de evaluación.
